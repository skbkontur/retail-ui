# Custom controls

Валидации работают не только с контролами [React UI](https://tech.skbkontur.ru/kontur-ui/), но и с собственными компонентами или обёртками над ними.
Для этого в таком контроле/обёртке необходимо обеспечить следующие пропсы:

- `ref` — DOM-элемент или компонент с методом `focus`. Нужен, чтобы при отправке формы прокрутить страницу к ошибке и поставить на неё фокус.
- `error` — `true`, когда нужно показать ошибку.
- `warning` — `true`, когда нужно показать предупреждение.
- `onBlur` — сообщает о потере фокуса. Без него не будут работать валидации с типом `lostfocus`.
- `onChange` — сообщает о начале ввода, чтобы <Link onClick={linkTo('ValidationWrapper', 'Docs')}><code>ValidationWrapper</code></Link> понимал, что пользователь редактирует поле.

```tsx static
interface CustomControlProps<Elem = HTMLElement> {
  ref?: React.ForwardedRef<Elem>;
  error?: boolean;
  warning?: boolean;
  onBlur?: React.FocusEventHandler<Elem>;
  onChange?: React.ChangeEventHandler<Elem>;
}
```

`ValidationWrapper` также передаёт проп `onValueChange`, как у контролов React UI. Если ваш компонент рендерит его в DOM, в консоли появится предупреждение `Unknown event handler property 'onValueChange'`. Чтобы его не было, уберите `onValueChange` из пропсов перед рендером, как в примере ниже.
