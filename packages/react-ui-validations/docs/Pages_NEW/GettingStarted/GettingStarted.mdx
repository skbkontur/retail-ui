# Обзор и начало работы

[GitHub](https://github.com/skbkontur/retail-ui/tree/master/packages/react-ui-validations) [![Version](https://img.shields.io/npm/v/@skbkontur/react-ui-validations?style=flat-square)](https://www.npmjs.com/package/@skbkontur/react-ui-validations)

`@skbkontur/react-ui-validations`— библиотека для валидаций форм и отображения ошибок в React-приложениях.

Реализует поведение и правила, описанные в [Контур.Гайдах](https://guides.kontur.ru/principles/validation/).

Совместима с компонентами из библиотеки [React UI](https://github.com/skbkontur/retail-ui/), но также [может использоваться с кастомными контролами](https://tech.skbkontur.ru/kontur-ui/?path=/docs/react-ui-validations_concepts-custom-controls--docs).

Пакет валидации упрощает работу с проверкой компонентов и отображением результата этой проверки. В пакете реализованы основные механики:

- когда подсветить контрол: при отправке формы, при потере фокуса или сразу;
- как показать сообщение об ошибке: текстом или в тултипе;
- как обработать сразу несколько невалидных полей в форме;
- как ведёт себя форма при ошибке и др.

Можно использовать базовое поведение из коробки, либо изменить и донастроить его под решаемую задачу.

## Как устроена валидация

Для создания валидации используется два компонента:

- `ValidationWrapper` — оборачивает конкретный компонент (поле ввода, чекбокс и т.п.), для которого нужно показать состояние валидации.
- `ValidationContainer` — оборачивает всю форму. Отвечает за общее поведение валидации внутри формы: например, скроллинг к первой ошибке.

```jsx static
<ValidationContainer>
  <ValidationWrapper validationInfo={...}>
    <Input/>
  </ValidationWrapper>
</ValidationContainer>
```

Состояние валидации передаётся через проп `validationInfo` в компоненте `ValidationWrapper`. Если всё в порядке — `validationInfo={null}`, поле выглядит обычным образом. Если есть ошибка — передаётся объект с сообщением: `validationInfo={{ message: 'Ошибка' }}`.
Сообщение об ошибке — это ReactNode, то есть можно передавать не только текст, но и произвольную вёрстку.

Это простое описание работы валидации, изучить полные возможности можно в других статьях документации:

- [Компоненты валидации](https://tech.skbkontur.ru/kontur-ui/?path=/docs/react-ui-validations_validations-components--docs) - описание, пропсы, методы и примеры для компонентов валидации `ValidationWrapper` и `ValidationContainer`
- [Валидация объектов](https://tech.skbkontur.ru/kontur-ui/?path=/docs/react-ui-validations_validator-objects--docs) и [валидация массивов](https://tech.skbkontur.ru/kontur-ui/?path=/docs/react-ui-validations_validator-arrays--docs)
- [Зависимые](https://tech.skbkontur.ru/kontur-ui/?path=/docs/react-ui-validations_validator-dependent--docs) и [независимые валидации](https://tech.skbkontur.ru/kontur-ui/?path=/docs/react-ui-validations_validator-independent--docs)

## Начало работы

1. Установите библиотеку в проект:

   `npm install --save @skbkontur/react-ui-validations`

2. Импортируйте обязательные компоненты валидации в проект:

   ```jsx
   import { ValidationContainer, ValidationWrapper } from '@skbkontur/react-ui-validations';
   ```

3. Оберните каждый валидируемый компонент и форму:

   ```jsx
   <ValidationContainer>
     <ValidationWrapper validationInfo={...}>
       <Input/>
     </ValidationWrapper>
   </ValidationContainer>
   ```

4. Настройте для компонента `ValidationWrapper` [правило и тип валидации](https://tech.skbkontur.ru/kontur-ui/?path=/docs/react-ui-validations_validations-components--docs).
