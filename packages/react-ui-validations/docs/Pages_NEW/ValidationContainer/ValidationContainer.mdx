## Использование

Методы `submit` и `validate` вызываются через `ref`:

```jsx
const container = useRef(null);

<ValidationContainer ref={container}>
  <ValidationWrapper validationInfo={...}>
    <Input />
  </ValidationWrapper>
  <Button onClick={() => container.current?.submit()}>Отправить</Button>
</ValidationContainer>;
```

## Примеры

### Отслеживание валидности

Колбэк `onValidationUpdated` вызывается, когда в форме появляется или пропадает видимая ошибка, и получает `true`, если ошибок нет. Ошибки с типом `submit` до отправки формы не учитываются.

<Story of={DocsStories.ExampleOnValidationUpdated} />

### Фокус после отправки

Метод `submit` показывает все ошибки, в том числе с типом `submit`, прокручивает страницу к первой из них и ставит на неё фокус. Аргумент `focusMode` задаёт, что получит фокус:

- `FocusMode.Errors` — первая ошибка, по умолчанию;
- `FocusMode.ErrorsAndWarnings` — первая ошибка или предупреждение;
- `FocusMode.None` — ничего. Аналог `submit(true)`.

<Story of={DocsStories.ExampleSubmitFocusMode} />

### Показ ошибок без фокуса

`submit(true)` показывает все ошибки, но не прокручивает страницу и не переводит фокус.

По Гайдам показывать ошибки на только что открытой пустой форме нельзя. Исключение — черновик: пользователь уже заполнял форму, и в ней остались ошибки. Для такого случая и подходит `submit(true)` при открытии формы.

<Story of={DocsStories.ExampleSubmitWithoutFocus} />

### Проверка перед отправкой

Метод `validate` работает как `submit` и возвращает `true`, если в форме нет ошибок. Предупреждения (`level: 'warning'`) форму невалидной не делают.

```jsx
async function handleSubmit() {
  if (await container.current?.validate()) {
    await save();
  }
}
```

<Story of={DocsStories.ExampleValidate} />

### Отступ при прокрутке

Проп `scrollOffset` задаёт отступ от краёв окна при прокрутке к первой ошибке. По умолчанию — `{ top: 50, bottom: 0 }`, это близко к отступу 48 px из Гайдов. Пригодится, если на странице есть липкая шапка или футер. Проп `disableSmoothScroll` отключает плавную прокрутку.

<Story of={DocsStories.ExampleScrollOffset} />

### Скрытые поля

Контейнер проверяет только отрисованные <Link onClick={linkTo('ValidationWrapper', 'Docs')}><code>ValidationWrapper</code></Link>. Если поле скрыто, его ошибка не влияет на результат `validate`, поэтому условия показа поля не нужно дублировать в правилах. Снимите галочку и нажмите «Отправить».

<Story of={DocsStories.ExampleDynamicFields} />

### Перемонтирование полей

Если форма уже проверена, ошибка поля сохраняется и после его перемонтирования. Нажмите «Отправить», затем переключите вкладку и вернитесь — поле останется подсвеченным.
