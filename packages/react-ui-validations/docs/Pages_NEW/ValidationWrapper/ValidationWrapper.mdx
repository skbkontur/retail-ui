## Использование

Внутри `ValidationWrapper` должен быть ровно один контрол. Обёртка передаёт ему пропсы `error`, `warning`, `onBlur`, `onChange` и `onValueChange`, поэтому из коробки работают все контролы React UI. Как подключить свой компонент — в разделе <Link onClick={linkTo('Custom Controls', 'Docs')}>Custom Component</Link>. Где и как показать сообщение, задаёт проп `renderMessage` — подробнее на странице <Link onClick={linkTo('renderMessage', 'Docs')}><code>renderMessage</code></Link>.

```jsx
<ValidationWrapper validationInfo={value ? null : { message: 'Укажите имя', type: 'submit' }}>
  <Input value={value} onValueChange={setValue} />
</ValidationWrapper>
```

Что можно передать в `validationInfo` — тип, уровень, сообщение и независимость — описано на странице <Link onClick={linkTo('ValidationInfo', 'Docs')}><code>ValidationInfo</code></Link>.

## Примеры

### validationInfo

Обязательный проп. Принимает результат проверки поля: `null`, если ошибок нет, или объект с полями:

- `message` — текст сообщения, можно передать любую вёрстку;
- `type` — когда показать ошибку: при потере фокуса (`lostfocus`, по умолчанию), при отправке формы (`submit`) или сразу (`immediate`);
- `level` — ошибка (`error`, по умолчанию) или предупреждение (`warning`);
- `independent` — проверять поле только при потере собственного фокуса.

Подробнее и больше примеров — на странице <Link onClick={linkTo('ValidationInfo', 'Docs')}><code>ValidationInfo</code></Link>.

### renderMessage

Задаёт, как показать сообщение: `tooltip(pos)` — в тултипе (по умолчанию `tooltip('right top')`), `text(pos)` — текстом справа или снизу, или своя функция. Подсветку контрола `ValidationWrapper` включает сам.

Подробнее и больше примеров — на странице <Link onClick={linkTo('renderMessage', 'Docs')}><code>renderMessage</code></Link>.
