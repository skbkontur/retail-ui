# ValidationWrapper

Обёртка для компонента, управляет свойствами валидации конкретного компонента.

```jsx static
<ValidationContainer>
  <ValidationWrapper validationInfo={...}>
    <Input/>
  </ValidationWrapper>
</ValidationContainer>
```

Дочерний компонент внутри `ValidationWrapper` должен быть один. `ValidationWrapper` контролирует его поведение через пропсы, используя соглашения основной библиотеки React UI.

Для работы с компонентом используется [React.cloneElement()](https://facebook.github.io/react/docs/react-api.html#cloneelement).

### Передача результата валидации (validationInfo)

Состояние валидации передаётся через проп `validationInfo`:

- Если всё в порядке — `validationInfo={null}`, поле выглядит обычным образом.
- Если есть ошибка — передаётся объект с сообщением: `validationInfo={{ message: 'Ошибка' }}`.

В `validationInfo` задаются поля:

- `type` — определяет вид валидации: сразу, при потере фокуса или при отправке формы;
- `level` — уровень валидации: ошибка или предупреждение;
- `message` — сообщение об ошибке.

#### Вид валидации (type)

[Описание видов валидаций в Контур.Гайдах](https://guides.kontur.ru/principles/validation/#Vidi_validatsii)

Допустимые значения: `"immediate" | "lostfocus" (по умолчанию) | "submit"`.

##### Мгновенная (immediate)

Мгновенная валидация отображается всегда.

<Story of={DocsStories.ImmediateValidation} />

Обратите внимание, что по Контур.Гайдам этот тип валидации рекомендуется использовать в исключительных случаях. Более приоритетными являются валидации по потере фокуса или при отправке формы.

##### По потере фокуса (lostfocus)

Валидация по потере фокуса отображается, когда контрол находится не в фокусе.

Такую валидацию можно сделать <Link onClick={linkTo('Validator/Independent')}>независимой</Link>.

#### Сообщение об ошибке (message)

[Описание сообщения об ошибках в Контур.Гайдах](https://guides.kontur.ru/principles/validation/#Soobscheniya_ob_oshibkah)

По умолчанию сообщение об ошибке отображается в тултипе справа от контрола.
Это поведение переопределяется с помощью пропа `renderMessage` компонента `ValidationWrapper` (см.ниже).

##### Тултип

[Описание в Контур.Гайдах](https://guides.kontur.ru/principles/validation/#Tultipi)

Сообщение внутри тултипа рендерится с помощью функции `tooltip`.

Функция принимает один аргумент, который позволяет задать позицию отображения тултипа. Тип аргумента — `TooltipExtendedPosition`,
то есть те же значения, что принимает prop `pos` компонента `Tooltip`.

Полные позиции вроде `top left` и `right middle` (`TooltipPosition`) работают без дополнительной настройки.
Короткие (`top`, `left`, `right`, `bottom`) и центрированные (`middle center`, `middle left`, `middle right`) позиции
требуют фича-флага `validationTooltipExtendedPositions`. Подробнее — на странице [Feature flags](https://tech.skbkontur.ru/kontur-ui/?path=/docs/react-ui-validations_displaying-feature-flags--docs).

<Story of={DocsStories.TooltipValidation} />

##### Текст

[Описание в Контур.Гайдах](https://guides.kontur.ru/principles/validation/#Krasnie_teksti_na_stranitse)

Текстовое сообщение рендерится с помощью функции `text`.

Функция принимает один аргумент, который позволяет задать позицию отображения текста. Если позициция не указана, позиция `right` будет установлена в качестве позиции по умолчанию. Возможные значения: `bottom | right`.

#### Переопределение сообщение об ошибке (renderMessage)

Способ кастомизации отображения сообщения об ошибке (не путать с
[подсветкой контрола](https://guides.kontur.ru/principles/validation/#13)).
Для определённых в Контур.Гайдах способов отображения ошибок используйте функции `tooltip` и `text` (значение по умолчанию: `tooltip('right middle')`).

### Переопределение tooltip

Для отрисовки тултипа используется стандартный [Tooltip](https://tech.skbkontur.ru/kontur-ui/?path=/docs/react-ui_overlay-tooltip--docs).
Возвращает функцию для рендеринга сообщения об ошибке в виде тултипа. Используется для передачи в `renderMessage`.

Аргументы:

- `pos`: позиция, передаваемая в prop `pos` компонента `Tooltip` из React UI.

Тип `TooltipExtendedPosition` совпадает с `TooltipProps['pos']` и включает:

- **стандартные** позиции (`TooltipPosition`): `top left`, `top center`, `right middle` и другие полные значения с направлением и выравниванием;
- **расширенные** позиции: короткие `top` | `bottom` | `left` | `right` и центрированные `middle center` | `middle left` | `middle right`.

Стандартные позиции работают без дополнительных настроек. Для расширенных позиций включите фича-флаг
[`validationTooltipExtendedPositions`](https://tech.skbkontur.ru/kontur-ui/?path=/docs/react-ui-validations_displaying-feature-flags--docs#validationtooltipextendedpositions).
Без флага в dev-режиме появится предупреждение, но позиция всё равно будет передана в `Tooltip`.

```jsx static
import { tooltip, ValidationsFeatureFlagsContext } from '@skbkontur/react-ui-validations';

<ValidationsFeatureFlagsContext.Provider value={{ validationTooltipExtendedPositions: true }}>
  <ValidationWrapper validationInfo={{ ... }} renderMessage={tooltip('top')}>
    {/* ... */}
  </ValidationWrapper>
</ValidationsFeatureFlagsContext.Provider>
```

### Переопределение text

Возвращает функцию для рендеринга сообщения об ошибке в виде текстового блока рядом с контролом.
Используется для передачи в renderMessage.

Аргументы:

- `pos`: управляет положением текста и принимает значения 'right' или 'bottom' для отображения сообщения справа или внизу соответственно.
