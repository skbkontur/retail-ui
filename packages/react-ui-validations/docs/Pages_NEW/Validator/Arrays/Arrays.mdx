# Валидация массивов

Массив — это список элементов, которые могут быть любого типа. Валидация массивов позволяет проверять каждый элемент отдельно.

Описание валидаций элементов массива реализовано аналогично описанию <Link onClick={linkTo('Validator/Objects')}>валидаций полей объекта</Link>.

## Массив примитивных типов

Если массив содержит простые значения, например, строки, то валидация проходит так же, как и для объекта, но с использованием метода `array`.

```jsx static
const validate = createValidator<string[]>(b => {
  b.array(x => x, b => {
    b.invalid(x => !x, "Укажите email", "submit");
    b.invalid(x => !x.includes('@'), "Неверный формат email");
  });
});
```

Здесь:

- `array` — метод, который прогружается до узла содержащего массив.
- `x => x` - указывает, что валидация применяется к самому массиву.

В колбэке задаётся правило для конфигурирования элемента массива.
Правило последовательно применяется ко всем элементам массива.

### Получение объектов валидаций

Метод `validate` возвращает дерево валидаций.

Чтобы получить валидацию для конкретного элемента массива, используется метод `getNodeByIndex`. Он возвращает узел дерева по индексу массива.
Объект валидации из узла дерева извлекается методом `get`.

```jsx static
const validation = validate(emails);
const validationInfo = validation.getNodeByIndex(0).get();
```

Получить узел можно и через индексатор в пути метода `getNode`.
**Это возможно только при явном указании индекса числом, без переменных, констант и замыканий.**

```jsx static
const item = validation.getNode((x) => x[0]).get();
```

Код ниже работать не будет, потому что путь содержит замыкание:

```jsx static
const index = 0;
const item = validation.getNode((x) => x[index]).get();
```

В таких случаях, например, в цикле, обращайтесь к узлу по индексу с помощью метода `getNodeByIndex`.

## Массив объектов

Если элементы массива сами являются объектами, то нужно использовать `prop`, чтобы пройти к полям этих объектов.

```jsx static
interface ContactInfo {
  name: string;
  email: string;
}

const validate = createValidator<ContactInfo[]>(b => {
  b.array(x => x, b => {
    b.prop(x => x.name, b => {
      //...
    });
    b.prop(x => x.email, b => {
      //...
    });
  });
});
```

## Вариации

Массив может находиться внутри другого объекта. В таком случае путь до него указывается прямо в методе `array`.

```jsx static
interface Root {
  items: string[];
}

const validate = createValidator<Root>(b => {
  b.array(x => x.items, b => {
    //...
  });
});
```

Можно также задать валидацию не только для элементов массива, но и для узла, в котором лежит массив.

```jsx static
interface Root {
  items: string[];
}

const validate = createValidator<Root>(b => {
  b.prop(x => x.items, b => {
    b.invalid(...); //правило для узла items
    b.array(x => x, b => {
      //...
    });
  });
});

const validation = validate(root);
const validationInfo = validation.getNode(x => x.items).get();
```
