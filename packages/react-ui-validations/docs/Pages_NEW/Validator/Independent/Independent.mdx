# Независимые валидации

По умолчанию все валидации зависимые, подробнее об этом — [Зависимые валидации](https://tech.skbkontur.ru/kontur-ui/?path=/docs/react-ui-validations_validator-dependent--docs).

При этом могут быть случаи, когда зависимость нужно убрать. Например, если проверять поля на пустое значение, то при потере фокуса по `lostfocus` на одном поле - подсветятся все, а такое поведение не рекомендуется по [Гайду](https://guides.kontur.ru/principles/data/validation/#Validatsiya_zavisimih_polei).

Чтобы сделать валидацию независимой, необходимо указать свойство `independent` в объекте `validationInfo`.

**Пример независимой валидации**

Валидации типа `lostfocus` можно сделать независимыми.
Такие поля будут валидироваться только при потере собственного фокуса. И не будут вызывать валидации у других полей с типом `lostfocus`.
