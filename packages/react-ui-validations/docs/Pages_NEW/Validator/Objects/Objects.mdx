# Валидация объектов

## Плоский объект

Базовый случай — это объект с простыми полями. Например, контактная информация с полями `name` и `email`.

Метод `createValidator` создает функцию валидации контракта данных указанного типа.

```jsx static
interface ContactInfo {
  name: string;
  email: string;
}

const validate = createValidator<ContactInfo>(b => {
  b.prop(x => x.name, b => {
    b.invalid(x => !x, "Укажите имя", "submit");
  });
  b.prop(x => x.email, b => {
    b.invalid(x => !x, "Укажите email", "submit");
    b.invalid(x => !x.includes('@'), "Неверный формат email");
  });
});
```

Здесь:

`prop` — метод, который указывает, до какого поля нужно пройти.

`invalid` — метод, который задаёт условие, при котором поле считается невалидным: сообщение об ошибке, тип валидации, уровень валидации и её независимость.

Можно задать несколько условий для одного поля, как в примере. Они будут проверяться по порядку, пока одно из них не сработает.

Вместо типа валидации можно передать объект `InvalidValidationInfo`, где все свойства необязательные:

```jsx static
interface InvalidValidationInfo {
  type?: Nullable<ValidationBehaviour>;
  level?: Nullable<ValidationLevel>;
  independent?: boolean;
}

b.invalid(x => !x, "Укажите имя", { independent: true });
```

### Получение объектов валидаций

Функция `validate` возвращает дерево валидаций по контракту данных.

```jsx static
const validation = validate(contactInfo);
```

Чтобы получить информацию о конкретном поле, используется метод `getNode`, а затем `get`.

```jsx static
const validationInfo = validation.getNode((x) => x.name).get();
```

Этот объект можно передать в компонент `ValidationWrapper` через проп `validationInfo`, чтобы отобразить ошибку в интерфейсе.

## Примитивный тип

Валидация примитивного типа, например, строки или числа, — это специальный случай, когда валидация происходит напрямую на значении и не требуется прогрузка до вложенных полей.

```jsx static
const validateEmail =
  createValidator <
  string >
  ((b) => {
    b.invalid((x) => !x, 'Укажите email', 'submit');
    b.invalid((x) => !x.includes('@'), 'Неверный формат email');
  });
```

В этом случае объект валидации получают напрямую из корня:

```jsx static
const validation = validateEmail(email);
const validationInfo = validation.get();
```

## Объект с вложенностью

Если в объекте есть другие объекты, то нужно использовать вложенные прогрузки через метод `prop`.

```jsx static
interface FullName {
  surname: string;
  name: string;
}

interface ContactInfo {
  fullName: FullName;
  email: string;
}

const validateContact = createValidator<ContactInfo>(b => {
  b.prop(x => x.fullName, b => {
    b.prop(x => x.name, b => {
      b.invalid(x => !x, "Укажите имя", "submit");
    });
    b.prop(x => x.surname, b => {
      b.invalid(x => !x, "Укажите фамилию", "submit");
    });
  });
  b.prop(x => x.email, b => {
    b.invalid(x => !x, "Укажите email", "submit");
    b.invalid(x => !x.includes('@'), "Неверный формат email");
  });
});
```

Чтение объекта валидации осуществляется через прогрузку до узла методом `getNode`.

```jsx static
const validation = validateContact(contactInfo);
const fullNameNode = validation.getNode((x) => x.fullName);
const nameNode = fullNameNode.getNode((x) => x.name);
const validationInfo = nameNode.get();
```

Чтобы получить данные валидации для вложенного поля, можно использовать цепочку вызовов:

```jsx static
const validation = validateContact(contactInfo);
const validationInfo = validation.getNode((x) => x.fullName.name).get();
```
