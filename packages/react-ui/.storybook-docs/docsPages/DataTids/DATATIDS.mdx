# DataTids

Атрибуты data-tid экспортируются для компонентов в виде объекта.
При необходимости добавления атрибута data-tid необходимо создать пулл-реквест.

У всех компонентов также есть проп data-tid, которым можно переопределять корневые дата-тиды.
