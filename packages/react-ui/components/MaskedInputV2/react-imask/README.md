# react-imask

React-обвязка и локальный форк ядра [imask](https://github.com/uNmAnNeR/imaskjs) для работы с масками ввода. Используется в компоненте **MaskedInput** дизайн-системы.

## Поддерживаемые типы масок

В публичном API поддерживаются только:

- **Строковая маска (pattern)** — `mask: string`, например `'0000-00-00'`, с опциями `definitions`, `blocks`, `placeholderChar` и т.д.
- **Регулярное выражение** — `mask: RegExp`.

Остальные типы масок из upstream (date, number, dynamic, enum, range, function, repeat) в этой сборке отключены; компонент **MaskedInput** работает только со строковыми масками.

## Экспорты

- **`IMask`** — фабрика: `IMask(element, opts)` создаёт экземпляр маски на DOM-элементе.
- **`IMaskInput`** — React-компонент с маской, обёрнутый в `forwardRef`. Используется через **FixedIMaskInput**, а не напрямую в приложениях.
- **`IMaskMixin`** — HOC для оборачивания своего инпута в логику imask (жизненный цикл маски, опции из пропсов). Из него собран класс для `IMaskInput`.
- **Типы**: `IMaskInputProps`, `IMaskMixinProps`, `ReactMaskProps`, `ReactMaskOpts`, `ExtractMaskOpts`, `ReactElementProps`, `ReactMixinComponent`, `MaskPropsKeys`.

Использование в коде библиотеки: **MaskedInput** передаёт опции в **FixedIMaskInput**, который рендерит **IMaskInput** с нужными пропсами и обработчиками.

## Контракт маски (MaskedInput)

Компонент **MaskedInput** принимает проп `mask` с человекочитаемыми символами и перед передачей в imask преобразует его:

- **`0`** — одна позиция для цифры. В строке маски каждый символ `0` заменяется на `{\\0}` (блок «0» в imask), который в ядре по умолчанию соответствует `/\d/`.
- Остальные символы маски (дефисы, скобки и т.д.) передаются как есть и трактуются imask как фиксированные.

**Definitions** (словарь правил для символов) по умолчанию в MaskedInput: `9` → `[0-9]`, `a` → `[A-Za-z]`, `*` → `[A-Za-z0-9]`. В ядре imask дополнительно есть встроенное определение `0` → цифра. При передаче `formatChars` в MaskedInput определения мержатся с дефолтными.

Пример: проп `mask="0000-00-00"` превращается в опции imask в маску `{\\0}{\\0}{\\0}{\\0}-{\\0}{\\0}-{\\0}{\\0}`.

## Отличия от upstream

- Урезанный набор типов масок (только pattern и regexp).
- Поддержка только `<input>` (без contenteditable).
- Логика завязана на React (mixin, пропсы, ref) и на контракт **MaskedInput** (подстановка `0` → `{\\0}` выше).
