## Пакет с компонентами для вёрстки таблиц

Возможности

- Компоненты &lt;Table.\* /&gt; с частями HTML-таблиц
- Фильтры и сортировки
- Выбор нескольких строк
- Действия со строками
- Вложенные таблицы

## Как подключить

```bash
npm i @skbkontur/table
```

```tsx
import { Table, useTableFilters, useTableSort, useTableRowSelection } from '@skbkontur/table';
```

```tsx
const container = { maxWidth: 420, width: '100%', overflowX: 'auto' };

<div style={container}>
  <Table size="small" minWidth="920px">
    {/* колонки и строки */}
  </Table>
</div>;
```

# Подвал (Footer) с итоговой строкой

Пример таблицы с иконками в строках и итоговой строкой в футере. Используйте `Table.Footer` для создания итоговой строки:

```tsx
<Table.Footer sticky>
  <Table.Row>
    <Table.Cell />
    <Table.Cell>
      <strong>Итого</strong>
    </Table.Cell>
    <Table.Cell currency>
      <strong>{formatNumber(total)}</strong>
    </Table.Cell>
  </Table.Row>
</Table.Footer>
```

# Группировка заголовков (colSpan/rowSpan)

Пример таблицы с многоуровневыми заголовками. Используйте `colSpan` для объединения ячеек по горизонтали и `rowSpan` для объединения по вертикали:

```tsx
<Table.Header>
  <Table.Row>
    <Table.HeaderCell rowSpan={2}>Организация</Table.HeaderCell>
    <Table.HeaderCell rowSpan={2}>Общая сумма, ₽</Table.HeaderCell>
    <Table.HeaderCell colSpan={2} bottomBorder>
      Стоимость продаж без НДС
    </Table.HeaderCell>
  </Table.Row>
  <Table.Row>
    <Table.HeaderCell>По ставке 18 %</Table.HeaderCell>
    <Table.HeaderCell>По ставке 10 %</Table.HeaderCell>
  </Table.Row>
</Table.Header>
```

# Размеры таблицы

Таблица поддерживает три размера: `small`, `medium` и `large`. Размер влияет на отступы, высоту строк и размер иконок в действиях.

```tsx
<Table size="small">{/* содержимое таблицы */}</Table>
```

При изменении размера таблицы рекомендуется также изменять размер иконок в действиях:

```tsx
const getIcon = (Icon16, Icon20, Icon24) => {
  switch (tableSize) {
    case 'small':
      return <Icon16 />;
    case 'medium':
      return <Icon20 />;
    case 'large':
      return <Icon24 />;
    default:
      return <Icon20 />;
  }
};
```

Можно просто передать size в иконки посмотреть и скопировать можно [тут](https://guides.kontur.ru/re/sources/icons/#bag-briefcase)

```tsx
<CdnIcon icon="bag-briefcase" size={24} weight="regular" />
```
