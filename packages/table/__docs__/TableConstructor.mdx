# Конструктор таблицы

Интерактивная демка фич `@skbkontur/table`. Тоглы сгруппированы по секциям, под таблицей — готовый код выбранной конфигурации с кнопкой «Скопировать».

**Размер** — `small` / `medium` / `large`.

**Колонки:**

- чекбоксы (выбор строк);
- иконка-индикатор в первой колонке (`noPaddingRight`);
- иконка внутри ячейки рядом с текстом.

**Строки:**

- разделители строк (выключаются через `noBottomBorder`).

**ActionBar** (зависимые тоглы задизейблены, пока действия выключены):

- действия со строкой (по умолчанию inline в отдельной колонке);
- показ поверх содержимого (`overlay`);
- скрытие действий в кебаб (`itemsVisible={0}`);
- опасное действие (`danger: true`).
