# useTableFilters

Хук для универсальной фильтрации данных таблицы. Поддерживает любые типы значений, строковые и кастомные предикаты, а также возврат уникальных значений для выпадающих фильтров.

## Сигнатура

```ts
const { filters, setFilters, setFilter, resetFilters, uniqueValues, filteredRows, convertFiltersToTokens } =
  useTableFilters(rows, columns);
```

### Принимает

- `rows: T[]` — исходные данные.
- `columns: ColumnFilterConfig<T, K>[]` — описание фильтруемых колонок.

`ColumnFilterConfig`:

```ts
{
  key: K;
  accessor?: (row: T) => any;          // по умолчанию row[key]
  stringifier?: (value: any) => string; // по умолчанию String(value)
  predicate?: (selected: string[], value: any) => boolean;
  filterPredicate?: (row: T, selected: string[]) => boolean; // более общий вариант
}
```

### Возвращает

- `filters: Map<string, any>` — текущее состояние фильтров.
- `setFilters(Map)` — заменить все фильтры целиком.
- `setFilter(key, value)` — установить фильтр для колонки.
- `resetFilters()` — сброс всех фильтров.
- `uniqueValues: Record<string, string[]>` — уникальные значения по колонкам (для DropdownFilter).
- `filteredRows: T[]` — массив после применения фильтров.
- `convertFiltersToTokens(): ITableFilterToken[]` — токены для UI (Table.FilterResultRow).

## Базовый пример

```tsx
const { filters, setFilter, uniqueValues, filteredRows, resetFilters, convertFiltersToTokens } = useTableFilters(
  data,
  columnConfig
);

const tokens = convertFiltersToTokens();
{
  tokens.length > 0 && <Table.FilterResultRow tokens={tokens} onResetAll={resetFilters} />;
}
```

## Советы

- Формируйте `columnConfig` так, чтобы `stringifier` совпадал с тем, что рендерится в таблице: это упростит совпадение фильтров.
- Для сложной логики используйте `filterPredicate`, если нужно учитывать несколько полей строки.
- Оборачивайте большие наборы данных в `React.useMemo`, чтобы не пересчитывать `uniqueValues` на каждый ререндер.
